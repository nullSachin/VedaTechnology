# Veda Technology Business & Services Website

A responsive, multi-section business website concept created as a web development internship project. It introduces technology learning, illustrative digital service areas, project-based experience, FAQs, and a contact enquiry form.

> **Content note:** This is a portfolio/demo implementation. Program and service descriptions are illustrative and should not be treated as verified claims about Veda Technology's current offerings. Confirm official details with the organization before publishing.

## Features

- Professional hero section with clear calls to action
- Responsive navigation with accessible mobile hamburger menu
- About section and value proposition cards
- Technology program cards and digital services list
- Internship/project-learning section
- Interactive FAQ accordion
- Contact form with inline name, email, and message validation
- Accessible status feedback and keyboard Escape handling
- Responsive layouts for desktop, tablet, and mobile
- Reduced-motion preference support and semantic HTML
- SEO description metadata

## Tech stack

- **HTML5** — semantic structure, sections, navigation, form controls
- **CSS3** — design system, Grid, Flexbox, media queries, transitions
- **Vanilla JavaScript** — mobile menu, FAQ interactions, inline validation, status messages

## Run locally

1. Download or clone the project.
2. Keep `index.html`, `style.css`, and `script.js` in the same directory.
3. Open `index.html` in a browser, or use the VS Code **Live Server** extension.
4. Resize the browser to test the responsive layout and mobile menu.

No package installation or build step is required. Google Fonts are loaded remotely; fallback fonts are used if they cannot be reached.

## Contact form behaviour

The form performs client-side validation and displays a confirmation message after valid input. **It does not send, save, or email the enquiry.** To make it functional, connect it to a secure backend or trusted form service and add server-side validation, spam protection, and an appropriate privacy notice.

## Customization checklist

- Replace illustrative content with organization-approved details.
- Add verified contact details and official links.
- Connect the form to an approved backend/form service.
- Test keyboard navigation, contrast, responsive layouts, and form errors.
- Use only project-approved images and brand assets.
- Test in current browsers and on real mobile devices before deployment.
