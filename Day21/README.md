# Responsive Navbar with Hamburger Menu

A modern and responsive navigation bar built using HTML5, CSS3, and JavaScript.

This project was developed as **Task 21** during my Web Development Internship at **Veda Technology**.

---

## 📌 Project Overview

The goal of this project was to create a responsive navigation system that provides a clean and consistent user experience across desktop, tablet, and mobile devices.

On larger screens, the navigation links are displayed horizontally. On smaller screens, the navigation automatically changes into a hamburger menu that can be opened and closed using JavaScript.
