# Sachin Kumar — Personal Portfolio Website

A clean, responsive personal portfolio website built as the first project of my web development internship with **Veda Technology**. It presents a developer introduction, skills, selected projects, education, internship experience, and a contact form in a polished single-page layout.

## Features

- Responsive navigation with an animated mobile menu
- Hero section with a concise developer introduction and calls to action
- About section describing learning goals and interests
- Skills grouped into frontend, backend/data, programming, and tools
- Project cards for WanderLust, the portfolio concept, and Stockly
- Timeline for internship experience and education
- Contact form with inline name, email, and message validation
- Accessible landmarks, skip link, keyboard-friendly controls, and reduced-motion support
- Responsive layouts for desktop, tablet, and mobile
- Dynamic copyright year

## Built With

- HTML5 for semantic structure
- CSS3 for layout, responsive design, effects, and custom illustrations
- Vanilla JavaScript for the mobile menu and form validation
- Google Fonts: DM Sans and Space Grotesk

## Run Locally

1. Download or clone this project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or run it with the VS Code Live Server extension.
4. Resize the browser or use device emulation to test the responsive navigation and layouts.

No package installation or build step is required.

## Customize Before Publishing

Update these placeholders in `index.html` with your real details:

- `your.email@example.com`
- `github.com/your-username`
- `linkedin.com/in/your-profile`

Review the skills and project descriptions to ensure they accurately reflect your current experience. The Stockly card is labelled as planned/in development. The contact form currently performs **client-side validation only**; it does not send email or save messages. Connect it to a secure backend or a form service if you need real submissions.

## Accessibility Notes

The page uses semantic HTML, a skip link, visible focus styles, labelled form fields, live status messages, and a `prefers-reduced-motion` media query. Continue testing with keyboard navigation and screen readers as you customize the site.

## Learning Outcomes

This project provides practice with semantic HTML, CSS Grid and Flexbox, responsive breakpoints, component-like section design, JavaScript event handling, DOM updates, basic form validation, and project documentation.
