# BMI Calculator

A responsive web-based BMI Calculator that allows users to enter their height and weight and calculate their Body Mass Index (BMI) along with the corresponding BMI category.

This project was developed as **Task 6 of my Web Development Internship** to practice JavaScript form handling, calculations, input validation, conditional statements, and DOM manipulation.

---

## 📌 Project Overview

The BMI Calculator provides a simple interface where users can enter their height in centimeters and weight in kilograms.

After submitting the values, the application calculates the user's BMI and displays the corresponding category.

The project also validates user input to prevent empty, invalid, zero, and negative values.
