## 🚀 Project Overview

The Image Carousel is a responsive web component that allows users to
browse through a collection of images.

The carousel supports both manual and automatic navigation.

Users can:

- Navigate to the next slide
- Navigate to the previous slide
- Select a specific slide using indicators
- View slides automatically
- Pause automatic rotation by hovering over the carousel
- Resume automatic rotation after moving the cursor away
- Navigate using keyboard arrow keys

---

## ✨ Features

### 1. Responsive Design

The interface adapts to:

- Desktop
- Tablet
- Mobile devices

CSS media queries are used to modify the layout for smaller screens.

---

### 2. Previous and Next Controls

Users can navigate between slides using the circular
previous and next buttons.

The carousel also wraps around when reaching the beginning
or end of the image collection.

---

### 3. Automatic Slide Rotation

Slides automatically change every 5 seconds.

JavaScript `setInterval()` is used to control the automatic rotation.

---

### 4. Pause on Hover

Automatic rotation pauses when the user moves the cursor
over the carousel.

Rotation resumes after the cursor leaves the carousel.

---

### 5. Slide Indicators

The bottom indicators show the current slide.

Users can click an indicator to directly move to a specific slide.

---

### 6. Keyboard Navigation

The carousel also supports:

- `Arrow Right` → Next slide
- `Arrow Left` → Previous slide

---

### 7. Smooth Transitions

CSS transitions are used to create smooth fade and scaling
effects between slides.
