# Temperature Converter

A responsive web-based temperature converter that allows users to convert temperatures between **Celsius, Fahrenheit, and Kelvin** in real time.

This project was developed as **Task 5 of my Web Development Internship** to practice JavaScript functions, form inputs, event handling, DOM manipulation, validation, and responsive frontend development.

---

## 📌 Project Overview

The Temperature Converter provides a simple and user-friendly interface for converting temperature values between three commonly used temperature scales:

- Celsius (°C)
- Fahrenheit (°F)
- Kelvin (K)

The conversion is performed dynamically as the user enters a value, without requiring a page reload.

---

## 🎯 Objective

The main objective of this project was to strengthen JavaScript fundamentals by implementing:

- Form and input handling
- JavaScript functions
- Temperature conversion formulas
- Event listeners
- DOM manipulation
- Input validation
- Responsive web design

---

## ✨ Features

- Convert Celsius to Fahrenheit and Kelvin
- Convert Fahrenheit to Celsius and Kelvin
- Convert Kelvin to Celsius and Fahrenheit
- Real-time conversion using the `input` event
- Validation for invalid temperature values
- Prevents temperatures below absolute zero
- Clear button to reset all inputs
- Responsive layout for desktop and mobile devices
- Simple and clean user interface
