## 📖 Project Overview

The Newsletter Signup Modal is a responsive web interface designed to encourage visitors to subscribe to a developer-focused newsletter.

The website contains a professional landing page along with a popup newsletter signup form.

The modal automatically appears after a short delay and allows users to enter their email address and subscribe.
