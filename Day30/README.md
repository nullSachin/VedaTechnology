# Task 30 — Custom 404 Error Page

A modern, responsive 404 error page built using HTML5 and CSS3 as part of my Web Development Internship at Veda Technology.

## Project Overview
A 404 error occurs when a requested webpage cannot be found. This project presents a friendly interface that explains the issue and provides a way to return to the homepage.

## Features
- Friendly custom 404 message
- CSS-only planet illustration
- Modern typography and color palette
- Responsive layout for desktop, tablet, and mobile
- Animated planet and decorative stars
- Hover effects on buttons and links
- Homepage navigation and contact link
- Keyboard focus indicators
- Reduced-motion support for accessibility
- No JavaScript dependencies

## Technologies Used
- **HTML5** — semantic structure and content
- **CSS3** — layout, styling, animations, and responsiveness
- **Google Fonts** — DM Sans and Space Grotesk

## Getting Started
1. Download or clone this project.
2. Open the folder in Visual Studio Code.
3. Keep `index.html` and `style.css` in the same directory.
4. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Design Highlights
- Soft background, white content surface, navy typography, and violet accents.
- CSS shapes and gradients create the planet, orbit rings, stars, and floating labels.
- Media queries adapt spacing and typography to smaller screens.
- Semantic HTML, visible focus styles, and reduced-motion support improve accessibility.

## Customization
- Replace the Northstar brand with your own website or project name.
- Update `href="index.html"` to point to your actual homepage.
- Replace `hello@example.com` with your contact email.
- Change the color variables in `:root` in `style.css`.
- Customize the error message and footer.

**Note:** This is a standalone front-end demonstration. A live website must be configured to serve this page for routes that cannot be found.
