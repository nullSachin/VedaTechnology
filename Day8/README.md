# Random Quote Generator

A simple and responsive Random Quote Generator built using HTML5, CSS3, and JavaScript.

This project was developed as **Task 8 of my Web Development Internship** to practice JavaScript arrays, objects, random numbers, event handling, DOM manipulation, and responsive web design.

---

## 📌 Project Overview

The Random Quote Generator displays a randomly selected quote along with its author whenever the user clicks the **New Quote** button.

The quotes are stored as objects inside a JavaScript array. The application uses `Math.random()` to select a quote and includes logic to prevent the same quote from being displayed twice consecutively.

An optional Share button is also included for sharing or copying the currently displayed quote.
