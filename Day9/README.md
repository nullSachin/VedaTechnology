# 🖼️ Responsive Image Gallery

A modern and responsive image gallery built using **HTML5, CSS3, and JavaScript**.

This project was developed as **Task 9 of my Web Development Internship** to practice CSS Grid, responsive layouts, JavaScript click events, DOM manipulation, and interactive UI components.

---

## 📌 Project Overview

The Responsive Image Gallery displays a collection of images in a modern grid-based layout.

Users can click any image to open it in a full-screen lightbox preview. The preview includes navigation controls, image information, and multiple ways to close the preview.

The project is fully responsive and adapts to desktop, tablet, and mobile screen sizes.

---

## ✨ Features

- Responsive image grid
- 12 images
- CSS Grid layout
- Image hover effects
- Image titles
- Full-screen image preview
- Lightbox/modal interface
- Previous and Next navigation
- Close button
- Click outside to close
- `Escape` key to close
- Left and Right arrow keyboard navigation
- Responsive mobile layout
- Semantic HTML
- Accessible image alt text
