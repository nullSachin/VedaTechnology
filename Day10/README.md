# ❓ FAQ Accordion

A clean, responsive, and interactive FAQ Accordion built using HTML5, CSS3, and JavaScript.

This project was developed as **Task 10 of my Web Development Internship with Veda Technology**.

---

## 📌 Project Overview

The FAQ Accordion is an interactive web component where users can click on a question to expand or collapse its answer.

The project focuses on creating a professional user interface while practicing DOM events, class manipulation, responsive design, and accessible interactive components.

---

## ✨ Features

- 10 FAQ questions
- Expand and collapse answers
- Multiple FAQ items can remain open
- Clear active state
- Smooth accordion animation
- Responsive design
- Mobile-friendly layout
- Hover effects
- Keyboard-accessible buttons
- Proper `aria-expanded` attributes
- Semantic HTML structure
- Clean and professional UI
- Reduced-motion support
