How the animation works

  1. Configure. Each bar stores its target in data-level, so changing a percentage means editing one number.
  2. Detect. An IntersectionObserver notices when a skill scrolls into view.
  3. Animate. JavaScript sets the fill's width, and a CSS transition on width does the smooth movement.
  4. Count. The percentage number counts up in step with the bar.
<div class="fill" data-level="90"></div>

.fill {
  width: 0;
  transition: width 1.3s ease-out;
}

const observer = new IntersectionObserver(
  (entries) => {
    entries.forEach((entry) => {
      if (!entry.isIntersecting) return;
      const fill = entry.target.querySelector(".fill");
      fill.style.width = fill.dataset.level + "%";
      observer.unobserve(entry.target);
    });
  },
  { threshold: 0.4 }
);
