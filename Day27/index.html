How the mapping works

Each condition name is a key. Its value holds the icon, text and readings, so the page looks up one entry instead of checking many if statements.

const WEATHER = {
  sunny: {
    label: "Sunny",
    icon: "☀️",
    description: "Clear skies and bright sunshine...",
    temperature: "28–36°C",
    humidity: "30–45%",
    wind: "8 km/h",
    tip: "Wear sunscreen and drink water."
  },
  rainy: { /* ... */ }
};

function render(key) {
  const data = WEATHER[key] || DEFAULT;
  // update icon, text, readings and background
}
  1. Select. The change event gives the chosen key, such as rainy.
  2. Look up. WEATHER[key] returns the matching icon, description and readings.
  3. Update. The text fills in and a data-condition attribute switches the background.
  4. Fall back. A missing or unknown key shows the default state instead of an empty page.
