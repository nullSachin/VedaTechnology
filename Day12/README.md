## 📖 Project Overview

The objective of this task was to create a responsive pricing table containing three different plans.

The pricing interface includes:

- Basic Plan
- Professional Plan
- Premium Plan

Each plan contains pricing information, a list of features, and a call-to-action button.

The Professional plan is highlighted as the **Most Popular** plan.

The interface was designed to be clean, modern, responsive, and easy to use.
